## What a good response looks like

1. **Direct answer first.** One to three short sentences, or one short line per step in a list. Length limit: 45 words for one fact, 80 for a multi-part answer, 70 for an emergency, 35 for a refusal.
2. **Only the guideline.** Every fact comes from the retrieved passages. Numbers, doses and units are copied exactly.
3. **Every sentence has a citation** like [1]. The source list under the answer shows the document, section and page.
4. **The right source.** The citation points to the passage that really holds the fact.
5. **Refuse when the guideline does not say.** If the topic is not covered, or the topic is covered but not the exact detail asked for (for example a dose), the answer is exactly: "I could not find this in the guideline documents I have."
6. **Plain words.** No "the passages", "the context" or "as an AI". No advice that is not in the guideline.
7. **Emergencies first.** If the question describes an emergency, the answer starts with the emergency step.

| Check | Passes when |
| --- | --- |
| Key facts included | every expected fact is in the answer |
| Refuses only when it should | refuses the 12 questions the guideline cannot answer, and none of the 23 it can |
| No made-up facts | no number outside the passages and none of the trap answers (wrong doses and so on) |
| Every sentence cited | at least 80% of sentences carry a valid [n] |
| Right source cited | a cited passage is on the expected page of the expected document |
| Short enough | within the word limit |
| Emergency step first | emergency questions mention the emergency step at the start |
| Plain style | none of the banned phrases |
| Section and page correct | for prompts that write them: section and page match the passage header |

A response passes only if every check that applies to it passes.
